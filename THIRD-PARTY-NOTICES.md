## BaiduPCS-Go

Copyright (c) 2016–2020 iikira. The original client and work derived from it are licensed under the Apache License, Version 2.0. [Apache-2.0 license text](licenses/Apache-2.0.txt)

BaiduPCS.NET adapts BaiduPCS-Go's account and Netdisk protocols, path and command behavior, transfer and checksum formats, and legacy encrypted-file format. The .NET port changes the command interface, error handling, state files, transfer scheduling, and release mechanism. The source baseline is commit `1b9131817aaf8ca7dee24bc00e33ebc4c7a5cc73` of qjfoidnh/BaiduPCS-Go. [Pinned upstream source](https://github.com/qjfoidnh/BaiduPCS-Go/tree/1b9131817aaf8ca7dee24bc00e33ebc4c7a5cc73)

Credit goes to iikira for the original BaiduPCS-Go and to qjfoidnh for maintaining the upstream fork. Authors in the fork's history through the baseline include 66Leo66, chgwan, dddddai, Felix Yan, kv-chiu, Mix, qjfoidnh, REcount110, ReveEver, Richard-Hu7-2, Rui Chen, rui, van, victorwoo, Wei Sun, yun.zhong, and dependabot[bot].

Issue reporters and pull request authors are credited in the review alongside their proposals and the changes informed by them. [Open upstream review](https://github.com/ajtn123/BaiduPCS.NET/blob/main/docs/upstream-review.md)

The Go modules Baidu-Login and baidu-tools were consulted for compatibility. The corresponding sign-in and host utilities use native .NET implementations.
